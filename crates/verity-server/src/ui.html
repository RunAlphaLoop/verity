Backfill initial historical sync, per source — GET /v1/admin/backfill

A backfill is a bounded job — a total, a running count, a terminal state — distinct from the Connectors heartbeat above, which is an unbounded liveness counter. Progress is best-effort telemetry: a missed post undercounts, never over. A source that can't be counted up front shows an indeterminate bar and a raw processed count, never a fabricated percentage.
