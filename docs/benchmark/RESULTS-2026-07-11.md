## Metric 2 — stale-citation rate after CDC supersession (target ~0)

**0 stale reads / 200 reads across 100 write→supersede→read cycles = stale-citation rate 0.** 0 consistency timeouts (reads that never saw v2 within 2s).

Each cycle writes fact v1, supersedes it with v2 through the debezium-envelope upsert sequence (L0 episode + deterministic bi-temporal L1 upsert, in-process — no HTTP hop), then immediately reads `current_fact` and BM25 `recall`. Any read returning v1 as current is a stale citation.

| read path | reads | stale | gap p50 | gap p95 | gap p99 |
|---|---|---|---|---|---|
| current_fact | 100 | 0 | 0.38ms | 0.61ms | 1.06ms |
| recall (BM25) | 100 | 0 | 11.43ms | 13.41ms | 15.21ms |

*Gap = elapsed from the v2 write commit to the first read observing v2, including that read's own latency.*

## Metric 4 — scoped-read latency at 1000005 chunks
